# 板块涨跌速览

状态：已迁移。2026-09-17 使用真实 API Key 完成同花顺 REST 链路联调（目录、指数快照、成分股、股票快照四个 capability 均返回 `code=0`），Provider、配置、测试、页脚数据来源与文档同步更新；东方财富实现及其回退链路已删除。

## 实现基准

实际开发以 `demo/board-performance-card/metric-demo.css` 的单卡视觉样式为基准；总览图的行业、概念分区与排行组合由 `src/renderer/board-performance-card.ts` 实现：

- `demo/board-performance-card/render-metric-demo.mjs`：单分类卡片 HTML 生成器与明确标注的示例数据。
- `demo/board-performance-card/metric-demo.css`：布局、配色、字体、圆角与阴影。
- `demo/board-performance-card/metric-demo.html`：生成的预览。
- `demo/board-performance-card/metric-demo.png`：设计截图。

Demo 中的排行数量仅用于展示单卡视觉，不代表机器人当前的 Top 10 总览规格。项目根目录运行 `node demo/board-performance-card/render-metric-demo.mjs` 生成预览，不手工修改生成文件。

## 指令与数据口径

群聊 `@bot 板块涨跌` 返回一张行业与概念板块总览图。图片上半部分为行业、下半部分为概念；每个分类均包含涨幅 Top 10 与跌幅 Top 10，共 40 张板块卡片，分类独立排序。

- 分类：行业使用 `GET /api/a-share-index/catalog/ths-index-list?tag=industry`，概念使用 `tag=cn_concept`；两者独立排行，不混入区域 `region` 或特色指数 `tszs`。
- 排名：对目录中的指数调用 `GET /api/a-share-index/prices/snapshot`，按 `price_change_ratio_pct` 数值分别取涨幅 Top 10 与跌幅 Top 10。该值已经是百分比数值，例如 `1.74` 表示 `+1.74%`。
- 关联股票：指数快照不直接提供领涨/领跌股。对实际展示的板块调用成分股接口，再批量取成分股快照；涨幅榜选涨跌幅最大成分股，跌幅榜选最小成分股，同值按完整 `thscode` 升序打破平局。
- 字段映射、认证、响应校验、限流、数据时间和失败处理以 [同花顺金融数据 API 接入调研](../ths-financial-data-api.md) 为准；实现和测试必须共同锁定该契约。

新版不展示走势图。正式实现仅使用上述同花顺板块数据链路，不通过分时走势、旧缓存或模拟值补缺。批量快照分块默认 100、可通过 `THS_SNAPSHOT_BATCH_SIZE` 调整（真实 Key 验证 100 与 200 均可用），分块请求共享受限并发（默认 3），所有请求使用 `X-api-key`，并在 `HTTP 429` 或 `code=4001` 时带抖动退避；不回退东方财富。

## 布局要求

浅灰背景，白底圆角小卡片，细边框、轻阴影。总览图以行业、概念两个上下分类区块组成；每个区块内的涨幅榜和跌幅榜并列展示，不设置卡片最小高度。

卡片从上到下：

1. 板块名称，常规字重，左对齐。
2. 大号加粗板块涨跌幅，红涨绿跌，平盘灰色，保留正负号与两位小数。
3. 底部左侧直接显示股票名称，右侧为浅色背景的股票涨跌幅标签和方向箭头，平盘使用横线。

股票名前不显示“领涨”“领跌”或“领涨股／领跌股”文字。股票仍按榜单方向选择，颜色由自身数值决定，与板块数值独立。

不显示走势图、排名角标和内部分隔线。正式图片标题区显示总览日期，每个分类区块显示各自的获取时间，页脚显示“数据来源：同花顺 · 仅供参考”，不使用 Demo 的示例标识。截图高度适配内容，避免旧版固定画布的大面积留白。

## 验收标准

1. 指令返回一张新版总览图片，行业与概念各 20 张板块卡片。
2. 行业、概念的涨幅、跌幅榜、板块涨跌幅和关联股票数据应符合 [已确认的同花顺接口口径](../ths-financial-data-api.md)。
3. 不依赖分时数据即可完成回复。
4. 布局与新版 Demo 一致，无股票文字前缀，窄屏无横向溢出。
5. 数据、渲染或发送失败时有明确提示，不发送旧数据或模拟值。
6. 更新数据源、无走势请求链路、渲染和指令测试，删除东方财富回退链路并清理测试临时文件。

## 暂不包含

- 分时走势、换手率、涨跌家数等扩展指标。
- 定时推送和用户自定义板块列表。
- 远程部署：待本地联调确认后另行安排。
